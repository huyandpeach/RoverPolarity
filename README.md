# Rover: Polarity

Rover: Polarity is a 2D puzzle-platformer prototype developed in Unity. Players control Rover, switch between the Lumis and Umbra states, interact with the environment, and collect Crystals to unlock the Portal.

The current prototype focuses on one playable level. Additional levels and challenges are planned as possible future improvements.

## Gameplay

- Switch between Lumis and Umbra to navigate state-restricted areas.
- Shoot light as Lumis to activate Light Receivers.
- Use Polarity Split to leave an Umbra clone while continuing as Lumis.
- Collect the required Crystals to open the Portal.
- Avoid traps and activate checkpoints to update the respawn position.

## Controls

| Action | Key |
|---|---|
| Move | A / D or Left / Right Arrow |
| Jump | Space |
| Switch between Lumis and Umbra | Q |
| Shoot light as Lumis | F |
| Activate or end Polarity Split | E |

Polarity Split can only be activated while Rover is in the Umbra state.

## Built With

- Unity 6.4 (`6000.4.8f1`)
- C#
- Unity 2D physics, sprites and Tilemaps
- TextMesh Pro

## Open the Project

1. Download or clone this repository.
2. Open Unity Hub and add the project folder.
3. Open the project using Unity `6000.4.8f1`.
4. Open `Assets/Scenes/MainMenu.unity`.
5. Press **Play** in the Unity Editor.
